How It Works

              
  1. 01Song or microphoneDifferent local source adapters
  2. 02Audio featuresFFT bands · RMS · transient · beat confidence
  3. 03Lighting engineN logical values · attack / release
  4. 04Hardware adapterMap N values to ten physical channels
  5. 05Web Serial → UNO R4Ten CSV values · 115200 baud

              
BeatSync measures signal energy and timing changes. It does not claim to understand song meaning. The live audio path stays in the browser; only metadata and lyric lookups use the local application service.

              
Pin mapping and limitations
PWM: D3, D5, D6, D9, D10, D11. Digital-only: D2, D4, D7, D8 (threshold 128). Each ordinary LED uses its own resistor.

            


            

              
✦
Project Notes

              
BeatSync is a deterministic audio-to-light engineering project. The browser owns audio analysis, lighting values, and USB serial output. Physical playback and hardware results remain pending until tested on the connected board.

              View verified milestones →
            


            

              
⌁
Limits & Future Scope

              
  • Four outputs use digital thresholding; they cannot dim smoothly.
  • Firmware has no frame acknowledgement, so physical brightness is not read back.
  • Beat/BPM and band mapping need testing across full songs and genres.

              
The virtual frame supports up to 100 configurable logical LEDs here. The current Arduino remains a 10-output monochrome proof; four channels are digital-only, and no device acknowledgement or physical brightness readback exists.
